CvBackend — NFT pipeline benchmark

Measures the detect → describe → match → estimateHomography → poseFromHomography pipeline and NftTracker's tracking state frame-by-frame, on this device, against a live webcam or a looped video file. Measurement only — nothing here changes how the pipeline runs, it only times it. Three modes share every parameter and call the backend the same way: stateless pipeline writes the detection calls out inline (as the static demo does); NftTracker, detection-only runs tracker.process() with detectionOnly: true — M1 of ADR-0001, which reports the same numbers as the stateless pipeline; NftTracker, tracking runs M2's LOST → DETECT → TRACK state machine, which needs a target with patches: targets/pinball.wnft, loaded from the file, never built here. In the tracking mode, ?detection=worker runs detection off the frame loop, in a module worker (js/detection-worker.mjs, over the bundle npm run build makes). Every run metric is defined once, in js/bench-metrics.mjs, and each export carries those definitions.
