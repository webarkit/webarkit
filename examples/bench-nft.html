CvBackend — NFT pipeline benchmark

Measures the detect → describe → match → estimateHomography → poseFromHomography pipeline frame-by-frame, on this device, against a live webcam or a looped video file. Measurement only — nothing here changes how the pipeline runs, it only times it. Two modes share every parameter and call the backend the same way: stateless pipeline re-implements the calls inline (as the webcam demo does), NftTracker runs tracker.process(). Milestone M1 of ADR-0001 is parity, so the two should report the same numbers here; the point of measuring both is to have a baseline once M2 gives the tracker state of its own.
