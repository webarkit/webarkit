CvBackend — live pinball demo

The same contract pipeline as the static demo, run on a live camera feed: detect → describe → match → estimateHomography → poseFromHomography, once per tick, with no state carried between frames. Hold the printed pinball flyer — or a phone/screen showing images/pinball.jpg — up to the camera.

Known limitation. Only the target is searched across pyramid levels; the live frame is detected at a single scale (levels: 1) to stay fast. That means the target has to appear at roughly its trained scale in view — closer or farther and matching can drop out. Real trackers (ARToolKit NFT/WebARKitLib) run an adaptive multi-octave pyramid on both sides; see examples/README.md for the measurements behind this and why it's next on the list rather than fixed here.

Camera access is required to run this demo.
