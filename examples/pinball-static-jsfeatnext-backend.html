CvBackend — static pinball demo

The whole contract pipeline on two still images: detect → describe → match → estimateHomography → poseFromHomography, with the backend chosen at construction. Static rather than webcam on purpose — the input is fixed, so anything odd on screen is the vision code and not the lighting, the focus, or the frame rate. The reprojected outline is the check that matters: if it lands on the target in the scene, every stage agreed.
